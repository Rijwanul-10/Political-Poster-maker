# 🎨 Poster Karigor — Frontend (Next.js 15)

The Next.js 15 frontend client for **Poster Karigor (পোস্টার কারিগর)**, featuring an iOS glassmorphism design system, bilingual (BN/EN) state management, and an administrative telemetry console.

## 🚀 Running Frontend Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
